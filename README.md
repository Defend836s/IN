# Instagram-агент для Claude (на русском)

Тринадцать скиллов для Claude, которые ведут аккаунт в Instagram. Бесплатно,
MIT, без регистрации, без API-ключей, ничего не нужно подключать.

Это русская адаптация набора
[instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill)
Джейка Шинкариола. Переведены все инструкции, шаблоны и отчёты, а Python-
инструменты научились понимать русский текст: русские словари штампов, падежи,
числа словами, рубли, темп русской речи. Английский текст они по-прежнему
понимают.

Один скилл пишет Reels по 26 формулам хуков и оценивает хук до того, как вы
потратите на него дубль. Один находит рилсы, которые реально работают в вашей
нише, и ранжирует их по тому, насколько каждый обогнал свой аккаунт. Один пишет
подпись и показывает ровно то, что видно в ленте до «... ещё». Один оценивает
профиль из 100 и переписывает то, что теряет баллы. Один планирует неделю.

И один - «очеловечиватель», благодаря которому остальными можно пользоваться.
Он вычищает из черновика длинные тире, «ёлочки», канцелярит, штампы нейросетей
и невидимые символы-водяные знаки, а потом оценивает остаток панелью из пяти
проверок, прежде чем вы его увидите.

**Ничего не публикуется, пока вы не скажете «да».** Эти скиллы пишут.
Публикуете вы.

## Установка

Вставьте в Claude:

```
https://github.com/defend836s/in

Установи этот скилл и проверь, что /ig-reel работает.
```

Или сами, в Claude Code:

```bash
git clone https://github.com/defend836s/in.git instagram-agent-ru
cp -r instagram-agent-ru/skills/ig-* ~/.claude/skills/
```

Или как плагин:

```
/plugin marketplace add defend836s/in
/plugin install instagram-agent-ru
```

Только для одного проекта, а не глобально: скопируйте те же папки в
`.claude/skills/` своего репозитория. Нет Claude Code совсем? Вставьте любой
`SKILL.md` в начало чата, и он заработает как режим. Вы потеряете пять
Python-инструментов, а это главное в `/ig-reel` и `/ig-human`, но остальное
работает.

Потом потратьте десять минут на `templates/voice.md`. Скопируйте его в
`~/.claude/instagram/voice.md` и заполните, или отправьте Claude три своих
рилса и скажите «напиши мой voice.md по этим». Этот файл читает каждый скилл.
Здесь он важнее, чем на других платформах, потому что слова нужно произносить
вслух.

## Тринадцать скиллов

| команда | что делает |
| --- | --- |
| `/ig-reel` | Одна идея в Reels. Три хука из [26 формул](skills/ig-reel/hooks.json) с оценкой, потом сценарий, текст на экране и раскадровка с таймингом. |
| `/ig-viral` | Находит, что работает в вашей нише, ранжирует по кратности над медианой каждого аккаунта, называет формулу и пишет свайп-файл. |
| `/ig-caption` | Подпись с проверкой. Показывает 125 символов, которые реально видны в ленте до тапа. |
| `/ig-carousel` | Карусели. Обложка, ради которой листают, текст слайдов и файлы 1080x1350. |
| `/ig-story` | Сторис на день, какой стикер для чего, и воронка в директ, где первым пишет зритель. |
| `/ig-profile` | Оценивает профиль по [рубрике из 12 пунктов](skills/ig-profile/rubric.json) из 100 и переписывает, начиная с главного. |
| `/ig-plan` | Неделя. Что публиковать, в каком формате, когда, и 10 аккаунтов для взаимодействия. |
| `/ig-human` | Очеловечиватель. Два скрипта, которые реально запускаются. См. ниже. |
| `/ig-comment` | Комментарии под чужими постами. Девять типов, выбор по тому, что за пост. Никогда не «🔥🔥🔥». |
| `/ig-reply` | Ветка под вашим постом. Сортирует на кодовое слово / клиент / по делу / вопрос / поддержка / шум и отвечает в этом порядке. |
| `/ig-dm` | Отправка по кодовому слову, первое сообщение, предложение о коллаборации и два напоминания. Два. |
| `/ig-repurpose` | Одно видео, подкаст или рассылка в неделю рилсов и каруселей, каждый из которых стоит сам по себе. |
| `/ig-audit` | Разбор опубликованного. Ранжирует по кратности и пересылкам на охват, а не по просмотрам. |

## Пять инструментов, которые реально запускаются

Без зависимостей (только стандартная библиотека Python 3), без сети, ничего не
загружается. Работают на вашей машине, с вашим текстом. Понимают русский и
английский.

### Хуки

```bash
python3 hookscore.py hooks.txt              # рейтинг вариантов
python3 beats.py script.txt --target 30     # засечь время до съёмки
```

```
РЕЙТИНГ ХУКОВ
==============================================================================
->  87.0 СИЛЬНЫЙ  Никто не говорит, что твои первые 30 рилсов должны провалит...
        слабое место: КОНКРЕТИКА (75)
    84.4 СИЛЬНЫЙ  Я потерял 180 000 ₽ из-за одного пункта в договоре.
        слабое место: ОБРАЩЕНИЕ (70)
    64.8 НОРМ     Стоп, не листай, если хочешь расти в Instagram в 2026 🔥
        слабое место: ОБРАЩЕНИЕ (90)
        стоп-фактор: Начинается с «не листай». Просить внимания - значит признать,
                     что вы его не заработали.
     9.6 СЛАБЫЙ   Всем привет, сегодня я хотела поговорить о контент-стратегии
        слабое место: СУТЬ В НАЧАЛЕ (0)
        стоп-фактор: Приветствие. В ленту никто не приходит, чтобы с ним поздоровались.
```

`beats.py` оценивает, сколько времени занимает каждая строка, складывает их в
таймкоды и отмечает четыре вещи, которые убивают Reels на монтаже: хук дольше
трёх секунд, бит настолько длинный, что зритель успевает уйти, серию строк без
конкретики и отсутствие петли к первой строке. По умолчанию 130 слов в минуту -
русские слова длиннее английских; для английского сценария `--wpm 165`. Повтор
слова из хука ищется с учётом падежей («договор» и «договоре» - одно слово).

```
РАСКАДРОВКА  ·  60 слов  ·  ~27.7 с при 130 сл/мин  ·  цель 30 с
========================================================================
  0:00.0   4.2с  ХУК        Я потерял 180 000 рублей из-за одного пункта в договоре.
                            ^ хук идёт 4.2 с, дольше 3 с
  ...
------------------------------------------------------------------------
  - Бит 1 произносится 4.2 с. Сократите до 6 слов или меньше, иначе хук
    прозвучит, когда решение уже принято.
  - Есть петля: последний бит повторяет «180 000, договоре, рублей» из хука.
    Повторные просмотры - бесплатный охват.
```

### Подпись

```bash
python3 caption.py caption.txt --keywords "договор с клиентом,цены на дизайн"
```

Instagram показывает в ленте около 125 символов подписи и прячет остальное за
тапом. Почти каждая неудачная подпись проваливается именно там. Поэтому первым
делом скрипт печатает это окно в рамке, так, как его читает незнакомец:

```
  ЧТО ВИДНО В ЛЕНТЕ
  +------------------------------------------------------+
  | Я потерял 180 000 рублей из-за одного пропущенного   |
  | пункта в договоре, и хуже всего то, что я перечитал  |
  | его дважды перед подпи                               |
  +--------------------------------------------- ... ещё +

  ОК     ДЛИНА            323 / 2200 символов
  ВНИМ   ПЕРВАЯ СТРОКА    129 символов, обрежется на 125 посреди мысли
  ОК     КОНКРЕТНЫЙ ХУК   чисел или имён в видимом окне: 2
  ВНИМ   ХЭШТЕГИ          тегов: 3, общих из них 1 (#рекомендации)
  ОК     ОДИН ПРИЗЫВ      один призыв к действию: кодовое слово в комментариях
  ВНИМ   ПОИСКОВЫЕ ФРАЗЫ  есть 1/2, в видимом окне 0. Нет: цены на дизайн
```

Он следит за текущим лимитом хэштегов - **пять на пост**, а не тридцать.
Instagram урезал его 18 декабря 2025 года. Общие теги вроде `#рекомендации`,
`#хочуврек`, `#тренды` отмечаются как пустые. Поисковые фразы ищутся с учётом
падежей.

### Очеловечиватель

```bash
python3 humanize.py draft.txt --report      # почистить, показать каждое изменение
python3 detect.py draft.txt                  # оценить, пять проверок
python3 detect.py before.txt after.txt       # показать разницу
```

**Что убирается автоматически:**

- **Невидимые символы.** Пробелы и соединители нулевой ширины, соединители
  слов, мягкие переносы, BOM, Unicode-теги, невидимые разделители,
  неразрывные и узкие пробелы. Ваша клавиатура их не печатает. Они переживают
  копирование и невидимы в любом редакторе.
- **Типографика.** В русском тексте длинное тире становится « - » (так печатают
  с телефона, и грамматика тире не ломается), «ёлочки» и „лапки“ - прямыми
  кавычками, многоточие одним знаком - тремя точками. В английском тексте, как
  в оригинале, тире становится запятой.
- **Словарь.** Около 150 русских штампов и 154 английских, с простыми заменами:
  канцелярит («стоит отметить, что», «на сегодняшний день», «таким образом»),
  обороты нейросетей («в современном мире», «давайте погрузимся в»,
  «уникальный», «ключевой», «комплексный» - во всех падежах) и инстаграмный
  блок: «стоп, не листай», «в этом видео я покажу», «подписывайся, чтобы не
  пропустить», «отметь друга, которому это нужно», «алгоритм любит», «залететь
  в реки». Всё лежит в [`slop.json`](skills/ig-human/slop.json), и словарь
  предназначен для правки.

**Что отмечается, но не исправляется:** «это не просто X, это Y», «не только
X, но и Y», правило трёх, вступление «в этом видео», канцелярит («является»,
«данный»), строки с «Давайте...», списки с эмодзи, три слова капсом подряд,
стены хэштегов, рефлекторные приманки, одинаковая длина предложений. Чтобы
поменять форму предложения, нужно суждение, поэтому такие места возвращаются
на переписывание, а не калечатся регуляркой.

На подписи, написанной так плохо, как только можно:

```
  РИТМ          ######..................  25.8    вариация 0.34
  КОНКРЕТИКА    ###############.........  62.7    3.9 детали на 100 слов
  ШТАМПЫ        ........................   0.0    19 штампов, 25.0 на 100 слов
  ОТПЕЧАТОК     ####....................  16.8    2 длинных тире, 2 «ёлочки»
  ГОЛОС         ........................   1.6    13 структурных примет
  ------------------------------------------------------------
  ЧЕЛОВЕЧНОСТЬ  ###.....................  12.8   ПОХОЖЕ НА ИИ
```

Живая подпись человека на ту же тему:

```
  ЧЕЛОВЕЧНОСТЬ  ##################......  78.0   ПРОЙДЕНО
```

### Свайп-файл

```bash
python3 swipe.py captured.tsv --out ~/.claude/instagram/swipe.md
```

Голые просмотры - не доказательство. Аккаунт на 2 000 000 подписчиков с 400 000
просмотров провёл тихий вторник. Аккаунт на 4 000 подписчиков с 400 000
просмотров что-то нашёл. `swipe.py` ранжирует по кратности над медианой
каждого аккаунта, называет формулу хука и показывает, чем верхняя треть
отличается от нижней. Колонки в TSV можно называть по-русски (`аккаунт`,
`подписчики`, `медиана`, `просмотры`, `хук`).

```
СВАЙП-ФАЙЛ  ·  роликов 4  ·  аккаунтов 4  ·  база: медиана аккаунта
==============================================================================
    60.0x  хук  82  #9  Укради                 @c                 180 000
           «укради это сообщение из четырёх строк, я два года его доводил»
    37.5x  хук  63  #3  Никто не говорит       @a                 412 000
           «никто не говорит, что первые 30 рилсов должны провалиться»
     1.3x  хук   0  -   без формулы            @b               1 200 000
           «всем привет, в этом видео я покажу свою утреннюю рутину»
```

## Что измерено, и что нет

Автор оригинала проверял английский оценщик хуков на 74 реальных хуках из
коротких видео (первые три секунды лучших и худших роликов пяти каналов):

1. **Плохие хуки он ловит хорошо.** Против десяти нарочно плохих хуков AUC
   0.83, девять из десяти оказались ниже медианы реального корпуса.
2. **Победителей он не выбирает.** Отличить удачные ролики автора от его же
   неудачных: AUC 0.56, где 0.50 - подброшенная монетка.
3. **Классификатор формул сначала узнавал 8% реальных хуков**, после
   переписывания регулярок по живой речи - 49%. На остальных он воздерживается,
   и это правильно.

**Русская версия на корпусе не проверялась.** Русские словари, основы слов и
регулярки формул написаны по примерам и проверены на них (все 26 русских
примеров из `hooks.json` классифицируются верно), но не на сотнях реальных
русских рилсов. Считайте оценки грубым фильтром очевидно слабых хуков, а
графику удержания верьте больше. Если прогоните на большой выборке и получите
другое - это ценно, присылайте.

## Мелкий шрифт, который и есть честная часть

**Эти скиллы не публикуют в Instagram.** Есть настоящий Content Publishing API
для профессиональных аккаунтов, и ему нужно приложение разработчика Meta,
привязанная страница, долгоживущий токен и проверка приложения, а этого скилл
выдать не может. Всё остальное, чем автоматизируют публикацию, комментарии,
подписки или директ, - это автоматизация браузера или сторонние сервисы, и
то и другое нарушает
[Условия использования Instagram](https://help.instagram.com/581066165581870)
и приводит к ограничениям аккаунта. Поэтому каждый скилл заканчивается одинаково:
блок, готовый к копированию, и публикуете вы. Это не ограничение, прикрученное
потом, это замысел, и поэтому шлюз одобрения настоящий, а не настройка.

Единственное исключение - автоответы на кодовое слово в директ, которые
Instagram поддерживает через свои инструменты и одобренных партнёров и которые
срабатывают только после того, как человек сам написал комментарий. `/ig-dm`
объясняет, где эта граница.

**`/ig-viral` читает, а не парсит.** Десять аккаунтов, по дюжине рилсов, с
человеческой скоростью, и браузером управляете вы. Он никогда не просит пароль
и не входит от вашего имени.

**Пять проверок на ИИ - локальные эвристики, а не API детекторов.** Они
построены по сигналам, на которые смотрят публичные детекторы, и полностью
работают на вашей машине. Это не GPTZero, Originality, Copyleaks, Winston,
Turnitin или text.ru, эти сервисы не вызываются, и их вердикты не обещаются.
Никто не может честно продать вам «необнаружимость».

**Проход по невидимым символам настоящий, и он узкий.** Он убирает символы
нулевой ширины и служебные символы, которые попадают в сгенерированный текст и
переживают копирование. Это не заявление о взломе криптографических водяных
знаков.

**Здесь ничего не выдумывается.** Никаких придуманных метрик, клиентов или
результатов под вашим именем. Если черновику нужна цифра, которой вы не дали,
он вернётся с `{{твоё число}}` и отметкой.

**Цифры платформы устаревают.** Лимит хэштегов сменился с 30 на 5 в декабре
2025 года. Если что-то здесь противоречит тому, что делает Instagram, когда вы
это читаете, прав Instagram.
