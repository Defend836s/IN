# Дзен: сайт-витрина + RSS-импорт

Импорт RSS в Дзене работает (проверено по официальной справке
dzen.ru/help/ru/website/site-to-channel.html и rss-modify.html). Но Дзен забирает
материалы **только с вашего сайта**: лента должна лежать на домене, привязанном к
каналу. Поэтому `build.py` собирает маленький сайт-витрину (страница на каждый ролик
и карусель) и ленту `dzen.xml` по спецификации Дзена.

```bash
python3 content/site/build.py --preview   # проба во временной папке
python3 content/site/build.py             # боевая сборка в site/ (нужен base_url)
python3 content/site/build.py --check     # проверить site/dzen.xml
```

## Что нужно сделать один раз

1. **Домен и хостинг.** Любой домен латиницей (кириллические Дзен не принимает) и
   хостинг статических файлов (Timeweb, Beget, REG.RU, GitHub Pages и т.п.).
   Впишите адрес в `site.yaml` → `base_url`.
2. **Канал в Дзене** с минимум 10 подписчиками (требование для подключения сайта).
3. **Студия Дзена** → Настройки → Свой сайт → добавить домен → подтвердить права:
   - «Метатег»: скопируйте значение в `site.yaml` → `dzen_verification`, соберите сайт;
   - или «HTML-файл»: положите выданный файл в корень сайта.
4. Соберите сайт (`build.py`), загрузите папку `site/` на хостинг.
5. В Студии: «Настроить трансляцию материалов сайта» → адрес ленты
   `https://ваш-домен/dzen.xml` → отправить на проверку. Статус - там же.

## Как работает

- Первая лента - 10 материалов (минимум Дзена), дальше `per_build` новых за сборку;
  в ленте только материалы за последние `keep_days` дня, повторно ничего не уходит
  (учёт - `state.json`).
- Ролики идут постами с MP4 (1080x1920, обложка - кадр ролика), карусели - постами
  с картинками. Хэштеги из подписи убираются.
- `mode: draft` - материалы падают в черновики канала: первое время проверяйте и
  публикуйте сами. `mode: publish` - публикуются сразу.
- Каждый материал перед добавлением проходит `compliance_check.py` (площадка dzen).
- Дзен может отклонить сайт без объяснения причин; повторная заявка - через 6 месяцев.
  Шансы выше, если на сайте регулярно появляются свои материалы (не меньше 3 в месяц).
