# Сеть Telegram-каналов

Агент `telegram-newsroom` ведёт новостные каналы (325 городов России от 50 тыс. жителей, список - `ГОРОДА.md`, из
`cities.yaml`, Россия, мир; новости только из российских изданий),
инвестиционный канал и канал аналитики матчей. Правила - `RULES.md`, каналы -
`channels.yaml`, инструменты - `tools/`.

## Что нужно сделать один раз (10 минут)

1. **Бот.** В Telegram: @BotFather → `/newbot` → скопируйте токен.
   Один бот на все каналы (и на автопостинг роликов тоже).
2. **Ключ.** Меню облачной среды в заголовке сессии → Edit → Environment variables:
   `TELEGRAM_BOT_TOKEN` = токен. В чат ключ не отправляйте.
3. **Каналы.** Создайте нужные каналы, добавьте бота администратором с правом
   публикации и впишите `chat` (`@имя_канала`) в `channels.yaml` (мир, Россия,
   инвестиции, прогнозы) или в `cities.yaml` (города) - или просто напишите Claude
   имена каналов, он впишет сам. Город без chat копит черновики.
4. Готово: «запусти новостной цикл», «обзор рынка», «прогнозы на завтра».

Пока ключа или chat нет, всё работает в режиме черновиков: посты копятся в
`telegram/drafts/<канал>/`, их можно посмотреть и опубликовать позже.

## Ключи для остальных площадок

Instagram, VK, YouTube, TikTok и другие - см. `content/autopost/README.md`.

## MAX (мессенджер)

Те же каналы ведёт агент `max-newsroom` через `tools/maxbot.py`.

1. **Бот.** Создаётся на платформе MAX для бизнеса (business.max.ru): нужен
   верифицированный профиль организации или ИП. Токен: Чат-боты → ⋮ → Настройки.
2. **Ключ.** В настройках облачной среды: `MAX_BOT_TOKEN` = токен. В чат не отправляйте.
3. **Каналы.** Добавьте бота администратором в каждый канал MAX, затем
   «найди мои каналы в MAX» - Claude запустит `maxbot.py discover` и впишет id в `max_chat`.
4. Сертификат Минцифры для домена API MAX уже лежит в `certs/` - ничего ставить не нужно.

Ограничения MAX: текст до 4000 знаков, 2 сообщения в секунду в канал, опросов в API нет.
