# Что нужно, чтобы всё работало само

Отмечайте выполненное. Ключи вводятся только в настройках облачной среды
(меню среды в заголовке сессии → Edit → Environment variables), не в чат.

## 1. Один раз, обязательно (без этого ничего не запустится)

- [ ] **Слить ветку в основную.** Вся работа - в ветке `claude/nice-goldberg-hn4w4l`.
      Запуски по расписанию открывают основную ветку. Скажите Claude «создай PR» и
      примите его на GitHub (или сделайте ветку основной в настройках репозитория).
- [ ] **Выключить GateGuard для автозапусков:** переменная `ECC_GATEGUARD` = `off`.
      Иначе проверка ECC будет останавливать агентов на каждом новом файле.
- [ ] **Telegram:** @BotFather → `/newbot` → `TELEGRAM_BOT_TOKEN`. Создать каналы
      («Все курсы мира» бесплатный и закрытый, нужные города, инвестиции, прогнозы),
      добавить бота администратором, прислать Claude имена каналов.

## 2. Когда будете готовы - по одной площадке

| Площадка | Что сделать | Переменные |
|---|---|---|
| MAX | бот на business.max.ru (нужна верификация организации/ИП), бот - админ каналов, «найди мои каналы в MAX» | `MAX_BOT_TOKEN` |
| VK Видео | токен пользователя-админа сообщества (права video, wall) | `VK_TOKEN`, `VK_GROUP_ID` |
| Одноклассники | приложение на ok.ru/devaccess + права у поддержки ОК | `OK_ACCESS_TOKEN`, `OK_APP_KEY`, `OK_APP_SECRET`, `OK_GROUP_ID` |
| YouTube | проект Google Cloud + OAuth; пройти аудит API, иначе ролики будут приватными | `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN` |
| TikTok | приложение TikTok for Developers; до аудита ролики видны только вам | `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`, `TIKTOK_REFRESH_TOKEN` |
| Pinterest | приложение и доска | `PINTEREST_TOKEN`, `PINTEREST_BOARD_ID` |
| Rutube | запросить API-доступ в поддержке Rutube | `RUTUBE_TOKEN` |
| Instagram / Facebook / Threads | приложение Meta; **сначала юрист** (реклама на ресурсах Meta в РФ) | см. `content/autopost/README.md` |
| Дзен | домен латиницей + хостинг, канал с 10 подписчиками, привязать сайт в Студии | `base_url` в `content/site/site.yaml` |

Rutube, Threads и картинкам Instagram нужен ещё `PUBLIC_MEDIA_BASE_URL` - адрес,
где лежат файлы роликов (подойдёт хостинг сайта для Дзена).

## 3. Решения, которые за вами

- [ ] **Срок акции** 1 511 ₽ (например «до 30 ноября») → `content/brand.yaml` → `promo.until`.
      Когда акция закончится - `enabled: false`.
- [ ] **Юрист, один раз:** маркировка рекламы своего канала (erid), продвижение на
      площадках Meta, регистрация каналов от 10 000 подписчиков в РКН, договоры
      с авторами курсов под рукой на случай жалоб.
- [ ] **Расписание:** сколько публикаций в день и в какое время (по умолчанию -
      1 ролик и 1 карусель в день на площадку, новости - каждые 2 часа с 7 до 23).

## 4. Дальше Claude делает сам

После пункта 1 скажите «запускай»: Claude опубликует первый пост и ролик для
проверки и поставит запланированные задачи - ролики, карусели, новости, обзор
рынка, статистику. Добавили новые ключи - площадка включается в тот же день.
Раз в неделю - отчёт: что вышло, что сработало, что поправить.
